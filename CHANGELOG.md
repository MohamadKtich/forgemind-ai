# Changelog

All notable changes to ForgeMind AI are documented here.

## 3.0.0 - 2026-07-22

### Added
- Bilingual Arabic/English interface with RTL support.
- Dark, light, and system themes.
- Predictive-maintenance, visual-quality, production, alert, report, digital-twin, and assistant modules.
- Role-based local authentication and administration.
- Real-data training pipelines for MetroPT-3 and KSDD.
- Model registry with provenance, metrics, status, and limitations.
- PostgreSQL and Supabase-ready backend configuration.
- Docker, CI, security documentation, contribution templates, and release assets.

### Important limitation
- Real-data model weights are not bundled. The included generic maintenance model is a local fallback trained on generated benchmark-style data.
