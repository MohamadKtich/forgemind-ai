# ForgeMind AI Release Notes

## GitHub-ready release

This release packages the complete local application and repository materials required for professional GitHub publication.

### Repository improvements

- English primary README and Arabic README.
- MIT license, author profile, citation metadata, security policy, contribution guide, code of conduct, changelog, and third-party dataset notice.
- CI workflow, Dependabot, issue forms, and pull-request template.
- Real application screenshot, architecture diagram, and GitHub social preview.
- Supabase PostgreSQL setup guide, generated schema, and database migration helper.
- Secret preflight scanner and expanded ignore rules.
- Author ownership added to application metadata and interface footer.

### Application status

- Backend test suite: 9 passing tests.
- Local SQLite operation remains the default.
- PostgreSQL URLs are normalized automatically for psycopg 3.
- Real-data training scripts remain optional and do not misrepresent fallback models as production-trained models.
