# ForgeMind AI Operations Walkthrough

1. Sign in as Factory Manager.
2. Review the dashboard KPIs, current risks, production trend, alerts, and recommended actions.
3. Open Machines and register or edit an asset.
4. Open a machine to review sensor history, diagnosis, feature drivers, maintenance work, alerts, and commands.
5. Start the Digital Twin and trigger a bearing, thermal, quality, or critical scenario.
6. Watch readings create new predictions, machine-state changes, alerts, and production records.
7. Create and complete a maintenance work order.
8. Open Quality Control, upload an image, and optionally include a golden reference.
9. Review the annotated result, measurements, defect categories, and inspection history.
10. Ask the Factory Assistant which machine should be maintained first and why.
11. Generate an Executive, Maintenance, Quality, Production, or Alert PDF report.
12. Sign in as Administrator to manage users, passwords, roles, factories, settings, and logs.
