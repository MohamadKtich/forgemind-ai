# Third-Party Dataset Notice

ForgeMind AI includes **training pipelines**, not redistributed copies, for the following datasets:

## MetroPT-3

Operational sensor data for an air-production unit used in a metro train. The pipeline is intended for predictive-maintenance and anomaly-detection experiments. Review and comply with the dataset's published attribution and license requirements before downloading or redistributing derived assets.

## Kolektor Surface-Defect Dataset (KSDD)

Industrial surface images and segmentation masks. Its published license includes non-commercial and share-alike conditions. The downloader requires explicit license acknowledgement, and the dataset is not included in this repository.

## Bundled fallback model

The bundled generic predictive-maintenance model is trained on generated benchmark-style industrial data. It is included for local application testing and must not be represented as a factory-validated production model.

Users are responsible for reviewing source licenses, attribution requirements, privacy constraints, and commercial-use restrictions before training or distributing models.
